# Contratempo E-Shop

Construye la aplicación e-commerce/PWA de Contratempo según el archivo index.html adjunto, usándolo como guía visual absoluta. Mantén la interfaz en italiano. Incluye Collezione con grid de relojes e imágenes placeholder, detalles reutilizables basados en Venatura Radica, carrello lateral oscuro con añadir productos, total en EUR y Checkout simulado, navegación responsive con menú hamburguesa, y configuración PWA instalable (manifest/service worker). Usa React y Tailwind, respetando estrictamente #050505, #a8794d y las tipografías Cormorant Garamond/Cinzel.
